# ai-image-captioning-vqa
# AI-Powered Image Captioning and Visual Question Answering (VQA)

## About the Project
This project uses Google's Gemini AI to understand images, generate captions, and answer questions about image contents.

## Features
- Upload and display images
- Generate image captions automatically
- Ask multiple questions about an uploaded image
- Receive AI-generated answers about image contents

## Technologies Used
- Python
- Google Colab
- Google Gemini API
- Pillow

## How to Run
1. Open the Jupyter Notebook in Google Colab.
2. Enter your Gemini API key securely.
3. Upload an image.
4. Generate an image caption.
5. Ask questions about the uploaded image.

## Applications
- Image understanding
- Visual question answering
- AI-powered image analysis
- Educational projects
